# 🌦️ Weather EDA Project

## 📌 Project Overview
This project presents an **Exploratory Data Analysis (EDA)** of weather data using Python and powerful data visualization techniques. The primary goal is to uncover meaningful patterns, trends, and relationships between various weather-related parameters such as:

- Temperature
- Humidity
- Wind Speed
- Visibility
- Atmospheric Pressure

The project follows a complete data analysis workflow — from raw data preprocessing to insightful visual exploration — helping to better understand weather behavior and environmental conditions.

---

# 🎯 Objectives
- Perform data cleaning and preprocessing
- Handle missing and inconsistent values
- Conduct statistical and exploratory analysis
- Visualize relationships between weather variables
- Extract meaningful insights from the dataset

# 📊 Exploratory Data Analysis Performed

### ✔ Data Cleaning & Preprocessing
- Removed duplicate records
- Handled missing/null values
- Checked data types and consistency

### ✔ Temperature Analysis
- Distribution of temperature values
- Apparent vs actual temperature comparison
- Seasonal temperature trends

### ✔ Humidity & Pressure Analysis
- Humidity impact on weather conditions
- Pressure variation across weather summaries

### ✔ Wind Speed Analysis
- Wind speed distribution
- Wind relationship with visibility and temperature

### ✔ Correlation Analysis
- Correlation heatmap between numerical variables
- Identification of highly correlated features

### ✔ Weather Condition Visualization
- Frequency analysis of weather summaries
- Visual comparison of different weather conditions

---

# 📈 Key Insights

- Humidity shows a strong relationship with apparent temperature.
- Certain weather conditions exhibit high visibility with lower pressure values.
- Temperature patterns vary significantly across different weather summaries.
- Correlation analysis helps identify dependencies between atmospheric variables.
- Visual exploration provides better understanding of hidden trends in the dataset.
